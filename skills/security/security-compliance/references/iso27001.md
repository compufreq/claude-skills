# ISO 27001 Reference

## ISO 27001 — ISMS Implementation

### Annex A Controls (Key Technical Controls)

| Domain | Control | Implementation |
|--------|---------|---------------|
| **A.5** | Information security policies | Documented policies in wiki/Confluence, annual review |
| **A.6** | Organization of infosec | CISO role, security team, responsibilities matrix |
| **A.8** | Asset management | CMDB, asset inventory, tagging in cloud |
| **A.9** | Access control | RBAC, MFA, SSO, quarterly access reviews |
| **A.10** | Cryptography | Encryption at rest (AES-256), in transit (TLS 1.2+) |
| **A.12** | Operations security | Change management, capacity planning, malware protection |
| **A.13** | Communications security | Network segmentation, firewalls, VPN |
| **A.14** | System acquisition & development | Secure SDLC, code review, security testing |
| **A.16** | Incident management | Incident response plan, tested quarterly |
| **A.17** | Business continuity | DR plan, BCP, tested annually |
| **A.18** | Compliance | Regulatory mapping, audit program |

### ISO 27001 Implementation Roadmap
```
Phase 1: Planning (2-3 months)
  → Gap assessment against Annex A
  → Define ISMS scope
  → Risk assessment methodology
  → Statement of Applicability (SoA)

Phase 2: Implementation (3-6 months)
  → Write/update policies and procedures
  → Implement technical controls
  → Train staff
  → Begin internal audits

Phase 3: Certification (2-3 months)
  → Stage 1 audit (documentation review)
  → Address findings
  → Stage 2 audit (implementation assessment)
  → Certification granted

Phase 4: Maintenance (ongoing)
  → Annual surveillance audits
  → Continuous improvement
  → Re-certification every 3 years
```

### Risk Assessment Template
```markdown
| Asset | Threat | Vulnerability | Likelihood | Impact | Risk Score | Treatment |
|-------|--------|-------------|-----------|--------|-----------|-----------|
| Customer DB | SQL injection | Unparameterized queries | Medium | Critical | High | Remediate: parameterized queries, WAF |
| API keys | Credential theft | Hardcoded in repo | High | High | Critical | Migrate to Secrets Manager |
| Backups | Data loss | No tested restore | Low | Critical | High | Monthly restore test |
```
