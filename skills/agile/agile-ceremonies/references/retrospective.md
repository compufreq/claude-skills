## 1. Core Retro Structure

Every retrospective follows this 5-phase structure, regardless of the specific activity:

| Phase | Purpose | Time % | Duration (90 min) |
|-------|---------|--------|-------------------|
| Set the Stage | Check-in, safety, ground rules | 10% | 10 min |
| Gather Data | The main retro activity | 30% | 25 min |
| Generate Insights | Find patterns, root causes | 25% | 20 min |
| Decide What to Do | Pick action items with owners | 25% | 20 min |
| Close the Retro | Appreciation, meta-retro | 10% | 10 min |

## 2. Full Facilitation Playbook

### Pre-Meeting Checklist
- [ ] Retro format chosen (rotate formats to avoid fatigue)
- [ ] Materials prepared (sticky notes, markers, digital board)
- [ ] Previous retro action items reviewed for status
- [ ] Sprint metrics gathered (velocity, bugs, incidents)
- [ ] Room booked / video call set up
- [ ] Anonymous feedback channel ready (optional)

### Phase 1: Set the Stage (10 min)

⏱️ Timer: 10 minutes
🎤 Speaker: Facilitator

📋 Script — Ground Rules:
> "Welcome to our Sprint [N] retrospective. Before we begin, let me set some ground rules:
> 1. Vegas rule — what's said here stays here.
> 2. We assume everyone did the best they could with what they knew.
> 3. We focus on the process, not the people.
> 4. Everyone's voice matters — I'll make sure everyone is heard.
> 5. We leave with concrete action items, not just complaints."

📋 Script — Previous Action Items:
> "First, let's check in on our action items from last retro:
> - [Action 1]: [Owner] — [Done/In Progress/Not Started]
> - [Action 2]: [Owner] — [Done/In Progress/Not Started]
>
> [If items are consistently not done]: We need to talk about why our retro actions
> aren't getting done. Is it a priority issue? A capacity issue?"

📋 Script — Safety Check:
> "Quick safety check — on a scale of 1 to 5, how safe do you feel sharing honest
> feedback today? Hold up your fingers. [Or use anonymous poll]
>
> [If average < 3]: Let's talk about what would make this space safer.
> [If 3-4]: Good. Remember, I'm here to facilitate, not judge.
> [If 5]: Great. Let's get into it."

📋 Script — Check-in Activity (pick one):
> Option A: "One word that describes this sprint for you."
> Option B: "Weather check — was this sprint sunny, cloudy, stormy, or something else?"
> Option C: "Rate the sprint 1-10 and say why in one sentence."

### Phase 2: Gather Data (25 min)

⏱️ Timer: 25 minutes
Run the chosen retro activity from Section 3 below.

### Phase 3: Generate Insights (20 min)

⏱️ Timer: 20 minutes
🎤 Speaker: Facilitator + Team

📋 Script:
> "Now that we have all this data, let's find patterns. I'm going to group similar items
> together. Help me — what themes do you see?"

Steps:
1. Cluster similar sticky notes / items into themes (5 min)
2. Name each theme (2 min)
3. Dot vote: each person gets 3 votes to place on themes they think are most important (3 min)
4. Discuss top 2-3 voted themes (10 min):
   - "Why is this happening?"
   - "What's the root cause?"
   - "Is this within our control?"

📋 Script for root cause:
> "For [top theme], let's do a quick '5 Whys':
> - Why is this happening? → [answer]
> - Why? → [deeper answer]
> - Why? → [even deeper]
> - Can we see the root cause now? What would fix it at the source?"

### Phase 4: Decide What to Do (20 min)

⏱️ Timer: 20 minutes
🎤 Speaker: Facilitator + Team

📋 Script:
> "Based on our top themes, let's pick action items. Remember:
> - We want 1 to 3 actions maximum. More than that and nothing gets done.
> - Each action needs an owner and a due date.
> - Make them SMART: specific, measurable, achievable, relevant, time-bound.
>
> For [Theme 1]: What's one concrete thing we can do next sprint?"

Action Item Template:
```
Action: [Specific action]
Owner: [Name — a person, not "the team"]
Due: [Date or "by Sprint N planning"]
Success Criteria: [How we know it's done]
```

⚠️ Watch-fors:
- "We should all try harder" → Not actionable. Ask: "What specific behavior change would help?"
- "Management should fix this" → What can WE do? Escalation can be an action item with a specific ask.
- Too many action items → "Let's pick the top 2 that will have the biggest impact."

### Phase 5: Close the Retro (10 min)

📋 Script — Appreciation Round:
> "Before we close, let's do a quick appreciation round. Who would you like to thank
> for something this sprint? It can be for anything — technical help, moral support,
> a great review, stepping up."

📋 Script — Meta-Retro:
> "How was this retro? On a scale of 1-5, how useful was this session?
> Anything I should change for next time?"

📋 Script — Closing:
> "Thanks everyone. Our action items are:
> 1. [Action] — Owner: [Name] — Due: [Date]
> 2. [Action] — Owner: [Name] — Due: [Date]
>
> I'll share these in our team channel. We'll review them at the start of next retro.
> Great sprint, team."

## 3. Retro Activity Formats

### Format 1: Start / Stop / Continue
**Best for:** General-purpose, any team, any sprint
**Time:** 20-25 min
**Materials:** 3 columns labeled Start, Stop, Continue

Instructions:
1. Silent writing (7 min): Everyone writes sticky notes for each column
   - **Start**: Things we should begin doing
   - **Stop**: Things we should stop doing
   - **Continue**: Things that are working well — keep doing them
2. Share & cluster (8 min): Each person places their notes and briefly explains (30 sec each)
3. Dot vote (3 min): 3 votes per person on most impactful items
4. Discuss top items (7 min): Deep dive on top-voted items

---

### Format 2: Mad / Sad / Glad
**Best for:** Emotionally charged sprints, after difficult releases
**Time:** 20-25 min
**Materials:** 3 columns labeled Mad 😡, Sad 😢, Glad 😊

Instructions:
1. Silent writing (7 min): Write notes expressing emotions about the sprint
   - **Mad**: Things that frustrated or angered you
   - **Sad**: Things that disappointed you or opportunities missed
   - **Glad**: Things that made you happy or proud
2. Share (8 min): Read notes aloud, grouped by emotion
3. Dot vote (3 min): Vote on items that resonate most
4. Discuss (7 min): Focus on Mad/Sad items to find actionable improvements

📝 Tip: Start with Glad to set a positive tone before digging into pain points.

---

### Format 3: 4Ls (Liked, Learned, Lacked, Longed For)
**Best for:** Teams focused on growth and learning
**Time:** 20-25 min
**Materials:** 4 quadrants

Instructions:
1. Silent writing (8 min):
   - **Liked**: What went well? What did you enjoy?
   - **Learned**: What did you learn? New skills, tools, insights?
   - **Lacked**: What was missing? Resources, skills, information?
   - **Longed For**: What do you wish you had? Tools, processes, support?
2. Share & cluster (8 min)
3. Dot vote (3 min)
4. Discuss (6 min): Focus on Lacked + Longed For for action items

---

### Format 4: Sailboat ⛵
**Best for:** Visual teams, strategic retrospectives, new teams
**Time:** 25-30 min
**Materials:** Drawing of a sailboat with: Wind (sails), Anchors, Rocks, Island

Instructions:
1. Explain the metaphor (2 min):
   - **Island** 🏝️ = Our goal / vision (where we're heading)
   - **Wind** 💨 = What's propelling us forward (things going well)
   - **Anchors** ⚓ = What's slowing us down (drag, tech debt, process issues)
   - **Rocks** 🪨 = Risks ahead (potential problems we see coming)
2. Silent writing (8 min): Place sticky notes on the appropriate area
3. Share (10 min): Walk through each area
4. Dot vote on Anchors and Rocks (3 min)
5. Discuss (7 min): How to cut anchors and avoid rocks

---

### Format 5: Starfish ⭐
**Best for:** When Start/Stop/Continue feels too simple
**Time:** 25 min
**Materials:** 5 sections in a star shape

Instructions:
1. Silent writing (8 min) — 5 categories:
   - **Keep Doing**: Working well, don't change
   - **More Of**: Good but we need more
   - **Less Of**: Doing too much of this
   - **Stop Doing**: Not adding value
   - **Start Doing**: New ideas to try
2. Share & cluster (8 min)
3. Dot vote (3 min)
4. Discuss top items (6 min)

---

### Format 6: Timeline / Sprint Journey
**Best for:** After eventful sprints, when specific incidents need discussion
**Time:** 30 min
**Materials:** Horizontal timeline with sprint days

Instructions:
1. Draw timeline (2 min): Mark sprint start, end, and key dates
2. Silent writing (10 min): Place events on the timeline with emotional indicators
   - 😊 Positive events (above the line)
   - 😐 Neutral events (on the line)
   - 😟 Negative events (below the line)
3. Walk through timeline (10 min): Discuss the journey chronologically
4. Identify patterns (5 min): "Do we see repeated issues? Timing patterns?"
5. Action items (3 min)

---

### Format 7: Happiness Radar
**Best for:** Regular pulse checks, distributed teams
**Time:** 20 min
**Materials:** Categories with happiness scales

Instructions:
1. Define categories (2 min): Process, Tools, Team, Delivery, Learning, Fun
2. Rate each category (5 min): Each person rates 1-5 for each category
3. Calculate averages (3 min): Find the lowest-scoring categories
4. Discuss bottom 2 (10 min): "Why is [category] low? What would move it up?"

---

### Format 8: Hot Air Balloon 🎈
**Best for:** Visual alternative to sailboat
**Time:** 25 min
**Materials:** Drawing of hot air balloon

Instructions:
1. Explain metaphor (2 min):
   - **Hot Air** 🔥 = What's lifting us up (energy, momentum)
   - **Sandbags** 🏋️ = What's weighing us down (problems, tech debt)
   - **Storm Clouds** ⛈️ = Threats on the horizon (risks)
   - **Sunny Skies** ☀️ = Opportunities ahead
2. Silent writing (8 min)
3. Share & cluster (8 min)
4. Dot vote on Sandbags + Storm Clouds (3 min)
5. Discuss (4 min)

---

### Format 9: DAKI (Drop, Add, Keep, Improve)
**Best for:** Action-oriented teams, process improvement focus
**Time:** 25 min
**Materials:** 4 quadrants

Instructions:
1. Silent writing (8 min):
   - **Drop**: What should we stop doing entirely?
   - **Add**: What new practice should we introduce?
   - **Keep**: What's working and should continue as-is?
   - **Improve**: What exists but needs to be better?
2. Share & cluster (8 min)
3. Dot vote (3 min)
4. Convert top items to SMART action items (6 min)

---

### Format 10: Lean Coffee
**Best for:** Teams with lots to discuss, democratic topic selection
**Time:** 30 min
**Materials:** 3 columns: To Discuss, Discussing, Discussed

Instructions:
1. Topic generation (5 min): Everyone writes discussion topics
2. Dot vote on topics (3 min): Each person gets 3 votes
3. Sort by votes (1 min): Highest votes discussed first
4. Discuss (20 min): Each topic gets 5 min. At 5 min, thumbs up/down to continue or move on.
5. Capture action items (1 min per topic)

---

### Format 11: Fishbone / Ishikawa
**Best for:** Root cause analysis of a specific problem
**Time:** 30 min
**Materials:** Fishbone diagram

Instructions:
1. State the problem (2 min): Write the specific issue at the "head" of the fish
2. Define categories (3 min): Standard: People, Process, Tools, Environment, External
3. Brainstorm causes (10 min): Place causes on the appropriate "bone"
4. Identify root causes (10 min): For each major cause, ask "Why?" repeatedly
5. Action items (5 min): Address the root causes, not the symptoms

---

### Format 12: Circles of Control
**Best for:** Teams feeling stuck, overwhelmed, or blaming external factors
**Time:** 25 min
**Materials:** 3 concentric circles

Instructions:
1. Draw 3 circles (1 min):
   - Inner: Things we CONTROL
   - Middle: Things we INFLUENCE
   - Outer: Things we cannot change (CONCERN only)
2. Silent writing (8 min): Place issues in the appropriate circle
3. Share (8 min)
4. Focus discussion on CONTROL + INFLUENCE (6 min):
   "What can we actually do about the things in our control?"
   "Who can we talk to about the things we can influence?"
5. Acknowledge CONCERN items (2 min): "We can't change these, but we can adapt."

## 4. Safety Check & Ground Rules

### The Prime Directive
Post this at every retro:
> "Regardless of what we discover, we understand and truly believe that everyone did
> the best job they could, given what they knew at the time, their skills and abilities,
> the resources available, and the situation at hand."
> — Norm Kerth

### Safety Check Methods
- **Fist of Five**: Hold up fingers 1-5 for safety level. Below 3 = address it.
- **Anonymous Poll**: Digital survey before starting. Share aggregate only.
- **Traffic Light**: Green = safe, Yellow = cautious, Red = not safe.

### When Safety Is Low
- Switch to anonymous input (written sticky notes, not verbal sharing)
- Use a neutral facilitator from outside the team
- Address the elephant: "I notice safety is low. Can someone share what would help?"
- Consider 1:1 conversations before the group retro

## 5. Action Item Tracking

### Action Item Template
```
| # | Action | Owner | Due Date | Status | Sprint Created | Sprint Closed |
|---|--------|-------|----------|--------|----------------|---------------|
| 1 | [Specific action] | [Person] | [Date] | Open | Sprint N | — |
```

### Rules for Good Action Items
- Maximum 3 per retro (focus > breadth)
- Each action has exactly ONE owner (not "the team")
- Due date must be within next sprint
- Action must be within the team's control or influence
- Write as specific behavior changes, not vague aspirations
- Review status at the START of next retro (accountability)

### Retro Agenda
```
# Sprint [N] Retrospective — [Date]
**Duration:** [X min] | **Facilitator:** [Name] | **Format:** [Activity Name]

## Agenda
| Time | Phase | Activity | Duration |
|------|-------|----------|----------|
| [Start] | Set the Stage | Check-in + safety check | 10 min |
| +10 | Gather Data | [Activity name] | 25 min |
| +35 | Generate Insights | Clustering + dot voting | 20 min |
| +55 | Decide What to Do | SMART action items | 20 min |
| +75 | Close | Appreciation + meta-retro | 10 min |

## Previous Action Items to Review
- [ ] [Action — Owner — Status]

## Ground Rules
- Vegas rule: what's said here stays here
- Prime Directive: we assume best intent
- Focus on process, not people
```

## 7. Choosing the Right Format

| Situation | Recommended Format |
|-----------|-------------------|
| First retro with a new team | Start/Stop/Continue (simple, familiar) |
| Team is emotionally drained | Mad/Sad/Glad (acknowledge feelings) |
| Routine sprint, nothing dramatic | 4Ls or DAKI (balanced) |
| Need strategic perspective | Sailboat or Hot Air Balloon |
| Specific incident to analyze | Fishbone or Timeline |
| Team feels powerless | Circles of Control |
| Team wants democracy | Lean Coffee |
| Team is in a rut with retros | Starfish or Happiness Radar (change of pace) |
| Repeat the same format max | 3 sprints in a row, then switch |

## 8. Anti-Patterns & Fixes

| Anti-Pattern | Fix |
|-------------|-----|
| Same format every sprint | Rotate. Use the table above. Retro fatigue is real. |
| No action items | Phase 4 is mandatory. "What's ONE thing we'll change?" |
| Action items never reviewed | Start every retro with action item review. Track in a visible doc. |
| Manager dominates | Manager should speak last, or not attend. Consider a non-manager facilitator. |
| Retro is canceled | Non-negotiable. If time is short, do a 30-min lightning retro. |
| Only negative discussion | Always start with what went well. Appreciation round at the end. |
| Same complaints every sprint | Dig deeper — use Fishbone. The symptom keeps recurring because the root cause isn't addressed. |
| "Everything is fine" | Safety is likely low. Use anonymous input. Or: "If ONE thing could improve, what would it be?" |
| Too many action items | Limit to 3 max. Better to do 2 well than 5 poorly. |
| No one wants to facilitate | Rotate facilitation. It's a skill-building opportunity, not a burden. |
